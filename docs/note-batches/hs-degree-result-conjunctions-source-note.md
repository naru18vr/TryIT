## ノートに反映する確認済み事項

Try IT公式は、程度・結果を表す構文を **so + 形容詞 + a + 名詞 + that + 節** と **such + a + 形容詞 + 名詞 + that + 節** として対比している。`so` は直後の形容詞を、`such` は `a` を含む名詞のかたまりを中心に修飾する。名詞を伴わない場合には、`so + 形容詞／副詞 + that + 節` の形も使われる。that以下は前から読めば結果、後ろから読めば程度として訳せ、意味内容は同じ構文を異なる順序で日本語にしている。

公式練習では、`that` の前後で区切って、前半の程度の強調と後半の結果を結び付ける読解手順を示している。Grammar Quizzesも、`so` を形容詞・副詞の前、`such` を形容詞と名詞のかたまりの前に置き、that節でその結果を表す形として説明している。ノートでは個別設問の文言・解答は転記せず、一般化できる形の判定、読解手順、よくある混同、復習観点を学習用に整理する。
