## ノートに反映する確認済み事項

Try IT公式は、ホテルの宿泊客・招待客を`guest`、コンサートなどの観客・聴衆を`audience`、乗客を`passenger`、依頼人を`client`として扱う。練習では訪問客`visitor`、スポーツなどの観客`spectator`、チャレンジでは店の客`customer`を扱う。

ノートでは、いずれも日本語では「客」になるが、場面（宿泊・公演・移動・専門家への依頼・訪問・スポーツ観戦・買い物）で語を選ぶことを復習観点として整理する。個別の設問・解答は転記しない。
