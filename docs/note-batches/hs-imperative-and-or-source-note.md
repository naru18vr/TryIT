# 高校英語文法「命令文＋and/or」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 命令文＋and | [Try IT「命令文＋and / or」](https://www.try-it.jp/chapters-4047/lessons-4052/) | `命令文, and 主語＋動詞 ...`は「…しなさい。そうすれば～。」を表す。後ろは肯定的な内容になる。 |
| 命令文＋or | [Try IT同単元のポイント](https://www.try-it.jp/chapters-4047/lessons-4052/) | `命令文, or 主語＋動詞 ...`は「…しなさい。そうしないと～。」を表す。後ろは否定的な内容・警告になる。 |
| 訳し分け | [Try IT同単元の練習](https://www.try-it.jp/chapters-4047/lessons-4052/practice-2/) | andは「そうすれば」、orは「そうしないと」と訳し、接続詞の後ろの内容が肯定か否定かで選ぶ。 |

## 対象動画

静的カタログから、正規動画 `46RzE4b4qFQ`（命令文＋and/or①）と `garK3Q_rPyk`（命令文＋and/or②）を確認した。

## ノート作成時の適用基準

文頭の動詞を命令文と確認し、後半が命令の結果・警告を表すかを意味から判定する。and／orを通常の単純な並列としてではなく、結果を導く定型表現として読む。
