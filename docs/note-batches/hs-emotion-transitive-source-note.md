# 高校英語文法「感情を表す他動詞」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 単元の主題 | [Try IT「感情を与える」他動詞](https://www.try-it.jp/chapters-3807/lessons-3852/) | 感情を与える他動詞では、現在分詞・過去分詞の使い分けに注意する。 |
| 現在分詞と過去分詞 | [英語学習ボックス「現在分詞と過去分詞の違い」](https://eigo-box.jp/grammar/present-participle-and-past-participle/) | 感情を表す他動詞の現在分詞は「感情を起こさせる側」、過去分詞は「感情を受ける側」を表す。 |
| 正規動画 | [Try IT公式動画①](https://www.youtube.com/watch?v=CSCbpmQUlig) | カタログ上の正規タイトルは「感情を表す他動詞①」。 |

## ノート作成時の適用基準

interest、surprise、bore、exciteなどは「人・物に感情を生じさせる」他動詞として扱う。感情の原因・性質を述べる場合は現在分詞、感情を抱く人・状態を述べる場合は過去分詞を選び、主語と分詞の能動・受動関係を必ず確認する。
