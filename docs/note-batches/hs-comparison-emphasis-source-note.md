# 高校英語文法「比較級の強調」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 基本の強調 | [Try IT「比較級（-er / more ～）」の強調](https://www.try-it.jp/chapters-3897/lessons-3906/) | 比較級の前にmuchを置くと、比較の意味を強められる。 |
| 日本語の読み方 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3897/lessons-3906/) | much taller、much more famousは「はるかに」「圧倒的に」などと訳せる。 |
| 追加の強調語と誤用 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3897/lessons-3906/practice-2/) | a lot、far、by farも比較級を強調できる。more longerやa lot of biggerは誤りで、a lot biggerは正しい。 |

## ノート作成時の適用基準

まず通常の比較級を完成させ、その直前にmuch、a lot、far、by farを置いて強調する。more＋比較級やa lot of＋比較級のように、比較級そのものを二重にしたり名詞用のofを挟んだりしない。much more＋原級は正しいが、more longerのようにmoreと-er比較級を重ねない。
