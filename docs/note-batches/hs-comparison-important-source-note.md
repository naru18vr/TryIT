# 高校英語文法「比較級の重要表現」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| know better than to do | [Try IT「比較級の重要表現」](https://www.try-it.jp/chapters-3897/lessons-3926/) | `know better than to＋動詞の原形` は「～するほどおろかではない」。 |
| no longer／more or less | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3897/lessons-3926/) | `no longer` は「もはや～ない」、`more or less` は「多かれ少なかれ」。 |
| all the 比較級 | [Try IT同単元の解説・練習](https://www.try-it.jp/chapters-3897/lessons-3926/practice-2/) | `all the 比較級 because S＋V`／`all the 比較級 for 名詞` は「～のためにより一層」。 |

## ノート作成時の適用基準

比較級の形が残る慣用表現は、語を一つずつ直訳せず、まとまりで意味を確認する。all the 比較級はbecauseの後ろが節、forの後ろが名詞であることを確かめる。know better than toは「より良い判断を知っている」という原義を手掛かりに、自然な日本語へ言い換える。
