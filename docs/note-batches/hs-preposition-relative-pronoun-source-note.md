# 高校英語文法「前置詞＋関係代名詞」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 基本形 | [Try IT「前置詞＋関係代名詞」](https://www.try-it.jp/chapters-3978/lessons-3995/) | 前置詞＋whom／whichを一組として、先行詞の直後から始まる関係詞節を作る。 |
| 物・人の区別 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-3995/) | 物の先行詞には前置詞＋which、人の先行詞には前置詞＋whomを用いる。 |
| 元の文への復元 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3978/lessons-3995/practice-2/) | `of whom you spoke`は元の`you spoke of the man`、`with whom I can talk`は元の`I can talk with a friend`に戻して前置詞を判定する。 |

## 対象動画

静的カタログのうち高校英語文法に該当する正規動画 `w_luelzOfPk`（前置詞＋関係代名詞①）と `wdSgMHcFi-I`（前置詞＋関係代名詞②）を確認した。高校英語構文の別動画 `SPM6KHD21wk` は指定順に従い、このバッチの対象外とした。

## ノート作成時の適用基準

元の文に戻して、動詞と先行詞の間に必要な前置詞を確認する。その前置詞をwhom／whichの前に置き、前置詞から関係詞節が始まる一まとまりとして読む。
