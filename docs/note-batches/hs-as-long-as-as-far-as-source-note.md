## ノートに反映する確認済み事項

Try IT公式は、どちらも「～限り」と訳せるものの、**as long as** は条件の「もし～ならば」または時の「～する間は」を、**as far as** は「～の限りでは」という範囲を表すと説明している。条件の as long as は `if` に、時の as long as は `while` に書き換えられる。as far as は知識・見解などの及ぶ範囲を示し、`if` の条件に置き換えない。

練習ページでは、期間の「～する間ずっと」と範囲の「知る限り」を、訳が同じ「限り」でも異なる表現として区別することを確認できる。英語学習ボックスの解説も、ifへ置き換えられるかを条件と範囲の実用的な判別手順として示している。ノートでは個別設問の文言・解答は転記せず、一般化できる選択手順、意味の違い、誤りやすい点、復習観点を学習用に整理する。
