# 高校英語文法「等位接続詞の重要表現」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| both・either・neither | [Try IT「等位接続詞の重要表現」](https://www.try-it.jp/chapters-4047/lessons-4056/) | `both A and B`は「AとBの両方」、`either A or B`は「AとBのどちらか」、`neither A nor B`は「AもBも～ない」。 |
| butを用いる重要表現 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-4047/lessons-4056/) | `not A but B`は「AではなくB」、`not only A but also B`は「AだけでなくBもまた」。いずれもBに内容上の重点がある。 |
| 並列部分の確認 | [Try IT同単元の練習](https://www.try-it.jp/chapters-4047/lessons-4056/practice-2/) | either/not onlyを見たら、対応するor/but alsoを探し、AとBに当たる語句を確定する。 |

## 対象動画

## ノート作成時の適用基準

定型表現を単なる訳語で覚えず、AとBがどの語句に当たるかを明示する。not A but Bとnot only A but also Bは、ともにBへ重点がある一方、Aが否定されるか含まれるかを区別する。
