## ノートに反映する確認済み事項

Try IT公式は、**so that + 主語 + 動詞** と **in order that + 主語 + 動詞** を「～するために」という目的を表す接続詞のかたまりとして扱い、**in case + 節** を「～するといけないから」「～という場合に備えて」と説明している。目的を表す `so that` の後ろには `can`、`will`、`may` などが、`in case` の後ろには `should` が来ることが多いという授業上の確認点も示されている。

Cambridge Dictionaryは、`so that` と `in order that` が目的を表し、助動詞とともに使われることが多いと説明している。今回は、Try ITの授業範囲に合わせ、`so as to + 動詞の原形`／`in order to + 動詞の原形` と、`so that + 主語 + 動詞`／`in order that + 主語 + 動詞` の形の違いも、接続詞の後ろには節が来るという形の識別として扱う。個別設問の文言・解答は転記せず、一般化できる規則、選択手順、誤りやすい点、復習観点を学習用に整理する。
