# 高校英語文法「関係代名詞whatの使い方2（慣用表現）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 主語の状態 | [Try IT「関係代名詞whatの使い方2」](https://www.try-it.jp/chapters-3978/lessons-4027/) | `what S is`は現在のSの姿・状態、`what S was / used to be`は過去のSの姿・状態を表す。 |
| 比較級・呼称 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-4027/) | `and what is 比較級`は「さらに～なことに」、`what is called / what we call`は「いわゆる～」を表す。 |
| 定型表現 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3978/lessons-4027/practice-2/) | `what little money S have`は少ないながらもSが持つ全てのお金、`A is to B what C is to D`は2組の関係が同じであることを表す。 |

## 対象動画

静的カタログから、正規動画 `_a2SLF4oifY`（関係代名詞whatの慣用表現①）と `h4XWdCR-Ka4`（関係代名詞whatの慣用表現②）を確認した。

## ノート作成時の適用基準

whatを含む表現を、単語ごとの直訳だけでなく定型のまとまりとして確認する。可変部分（主語・時制・比較級）と固定部分を分け、主な意味と誤りやすい形を明示する。
