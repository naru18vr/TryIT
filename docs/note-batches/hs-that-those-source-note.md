## ノート作成に反映する確認済み事項

* that／thoseは同じ名詞のくり返しを避けるための代名詞として使う。
* 繰り返す名詞が単数ならthat、複数ならthoseを用いる。
* `that of ...`や`those in ...`では、前に出た名詞を置き換えている。
* 何を置き換えるかは、比較される二つの語句で重複する名詞を探して決める。
* thoseは複数の人を表すことがあり、形容詞を後ろに置く`those present`で「出席者」を表せる。
