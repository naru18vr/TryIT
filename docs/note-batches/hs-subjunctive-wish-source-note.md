# 高校英語文法「I wish＋仮定法」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| I wish・If onlyの働き | [Try IT「I wish＋仮定法」などの表現](https://www.try-it.jp/chapters-3856/lessons-3861/) | I wish・If onlyは、後ろが現実と異なる内容を表す仮定法であることを示す表現。 |
| 現在への願望 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3856/lessons-3861/practice-2/) | 現在についての反事実的な願望は過去形を使い、be動詞はwereを用いる。 |
| 現在・過去・未来の願望 | [英語学習ボックス「I wish 仮定法」](https://eigo-box.jp/grammar/i-wish/) | 現在はI wish＋仮定法過去、過去はI wish＋仮定法過去完了、実現可能性の低い未来への願望はI wish＋S would doで表す。couldは後ろで使える。 |

## ノート作成時の適用基準

この2本ではI wish・If onlyを「願望の内容が現実と異なることを知らせる合図」として説明する。動画範囲に合わせ、主に現在の願望では過去形・were・couldを使うことを扱う。過去への後悔や未来への願望は、時制の基準とともに後続動画で区別する。
