# 高校英語文法「倒置の仮定法（Ifの省略）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| If省略と倒置 | [Try IT「倒置の仮定法（Ifの省略）」](https://www.try-it.jp/chapters-3856/lessons-3869/) | 仮定法のifは省略でき、その場合は残った条件節を疑問文の語順にする。 |
| 変換手順と訳し方 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3856/lessons-3869/practice-2/) | `If I were ...` はifを消してから倒置し、`Were I ...` となる。意味・訳し方はifを使った文と同じ。 |
| 直説法との区別 | [進研ゼミ高校講座「仮定法過去（完了）と直説法の違い」](https://benesse.jp/kyouiku/teikitest/kou/english/english/k00122.html) | 事実に反する・可能性のほとんどない内容は仮定法を用いる。可能性のある条件は直説法のif節で表す。 |

## ノート作成時の適用基準

If省略を単なる語の削除と説明せず、必ず倒置を伴う二段階の変換として示す。`Were I ...`、`Had I ...`、`Should ...`など、疑問文の形に見えても質問ではなく反事実的・仮定的な条件を示す文であること、訳は省略前のif節と同様に「もし～ならば」とすることを扱う。
