# 高校英語文法「カンマのついた関係代名詞2（which）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 固有名詞への補足 | [Try IT「カンマのついた関係代名詞2」](https://www.try-it.jp/chapters-3978/lessons-4015/) | 固有名詞の物の後に`, which ...`を置き、「ちなみに・そして…」という補足を加えられる。 |
| 文・節を受ける用法 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-4015/) | `, which ...`は前の名詞だけでなく、前の文全体または文の一部を受けて、その内容へ説明を加えられる。 |
| 読解時の確認 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3978/lessons-4015/practice-2/) | whichが前の名詞・発言内容・文全体のどれを指すかを意味から判定し、「そしてそれは」「しかしそれは」などでつなげて読む。 |

## 対象動画

静的カタログから、正規動画 `47HFld8nkOA`（whichの非制限用法①）と `SR5L_jTNkfA`（whichの非制限用法②）を確認した。

## ノート作成時の適用基準

カンマ＋whichの直前にある名詞だけを見るのではなく、which以下の述語と意味が自然につながる対象を探す。前文・前節の内容を受ける場合には、whichを「そのこと」として読み、補足情報として処理する。
