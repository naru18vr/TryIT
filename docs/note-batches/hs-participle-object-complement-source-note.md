# 高校英語文法「目的格の補語となる分詞」ファクトチェック記録

## 確認した一次情報

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 対象単元 | [Try IT「see 人 分詞」「keep 人 分詞」などの表現](https://www.try-it.jp/chapters-3807/lessons-3820/) | `see / 人 分詞`、`keep / 人 分詞` と区切り、目的語が分詞の状態である内容を表す。 |
| 現在分詞・過去分詞 | [Try IT同単元のポイント解説](https://www.try-it.jp/chapters-3807/lessons-3820/) | 能動・進行の状態は現在分詞、受身の状態は過去分詞を用いる。 |
| 知覚動詞との相違 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3807/lessons-3820/practice-2/) | `see 人 原形`は動作全体、`see 人 Ving`は動作の一部・進行中の場面を見るニュアンスを表す。 |
| keepの表現 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3807/lessons-3820/practice-2/) | `keep 人 waiting`は「人を待たせておく」。目的語と分詞の関係を確認する。 |

## ノート作成時の適用基準

`see / 人 分詞`・`keep / 人 分詞`の区切りを明示し、目的語が動作を行うのか、行為を受けるのかで現在分詞・過去分詞を選ぶ。原形不定詞との違いは、Try IT公式の説明にある知覚の範囲（全体／一部）に限定して記述する。
