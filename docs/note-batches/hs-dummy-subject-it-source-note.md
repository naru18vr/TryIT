## ノート作成に反映する確認済み事項

* 仮主語の`it`は具体的な物を指さず、文頭で主語の位置を占める。
* `It is + 形容詞 + to V`では、`to V`が本当の主語である。
* `It is + 形容詞 + that S V`では、that節が本当の主語である。
* 本当の主語が長いと、文頭に置くと頭でっかちになるため、英語では仮主語itを置いて本当の主語を後ろに回す。
* 人の性格・性質を表す形容詞では、`It is + 形容詞 + of 人 + to V`の形で、行為をした人を評価する。
