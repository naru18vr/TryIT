# 高校英語文法「カンマのついた関係副詞」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| カンマ＋where | [Try IT「カンマのついた関係副詞」](https://www.try-it.jp/chapters-3978/lessons-4019/) | 特定できる場所の後の`, where ...`は「そして・ちなみにその場所で…」という補足を付け加える。 |
| カンマ＋when | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-4019/) | 特定できる時の後の`, when ...`は「そして・ちなみにその時に…」という補足を付け加える。 |
| whichとの判別と制約 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3978/lessons-4019/practice-2/) | まず`, which`でつなげられるかを確認し、前置詞＋whichの置き換えになるときにwhere／whenを用いる。`, why`と`, how`は用いない。 |

## 対象動画

静的カタログから、正規動画 `NoNpbYa5-Ns`（where/whenの非制限用法①）と `j3F7s7qQFio`（where/whenの非制限用法②）を確認した。

## ノート作成時の適用基準

場所・時を表す名詞を見ただけでwhere／whenを選ばず、元の文で前置詞＋whichにできるかを確認する。カンマ付きの補足として読み、whereは場所で、whenは時での出来事を示す。
