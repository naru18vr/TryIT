- Try IT高校英語文法一覧: https://www.try-it.jp/k/english_grammar/

公式一覧に記載された順序を優先し、動詞の①・②を同じトピックの品質確認バッチとして登録する。個々のノートでは、公式レッスンのポイント・練習、正規動画ID、カタログタイトルを照合した事実だけを使用する。
