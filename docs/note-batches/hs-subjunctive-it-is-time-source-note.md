# 高校英語文法「It is time＋仮定法過去」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 基本形と意味 | [Try IT「It is time＋仮定法過去」の表現](https://www.try-it.jp/chapters-3856/lessons-3893/) | `It is time＋主語＋過去形` は「主語は～するべき頃だ」を表す。 |
| 過去形を使う理由 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3856/lessons-3893/) | 実際にはまだ行われていない、本来あるべき状態と現実の差を表すため仮定法過去を用いる。 |
| 表現の強さ | [Try IT同単元の練習](https://www.try-it.jp/chapters-3856/lessons-3893/practice-2/) | `It is about time` は「そろそろ～すべき頃」、`It is high time` は「とっくに～すべき頃」で、いずれも仮定法過去を続ける。 |

## ノート作成時の適用基準

It is timeの直後ではなく、主語の後ろの動詞を過去形にする。意味は単なる時刻の案内ではなく、まだ行われていない行動を促す「～すべき頃」である。aboutとhighが付く場合は、促しの強さを日本語訳にも反映する。
