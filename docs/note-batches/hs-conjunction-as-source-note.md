## ノートに反映する確認済み事項

Try IT公式は、接続詞 `as` の代表的な訳を、様態の「～のように」、比例の「～につれて」、時の「～すると」、理由の「～なので」、譲歩の「確かに～だが」の5つとして整理している。`as + 主語 + 動詞` という形だけでは意味を一つに決められず、as節と主節の関係を文脈から捉えることが重要である。時を表す `as` は `when` より同時性を強く表せると説明されている。

練習ページでは、文脈から理由を表す `as` を判定すること、形容詞などを文頭に出す倒置を伴う `形容詞 + as + 主語 + 動詞` が譲歩を表すことを確認できる。後者は、譲歩の部分を強調するときに用いる。ノートでは個別設問の文言・解答は転記せず、一般化できる意味の選択手順、倒置の見分け方、誤りやすい点、復習観点を学習用に整理する。
