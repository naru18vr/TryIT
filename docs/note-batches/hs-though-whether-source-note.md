# 高校英語文法「譲歩を表す接続詞1（though / whether）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| though・although | [Try IT「譲歩を表す接続詞1」](https://www.try-it.jp/chapters-4047/lessons-4080/) | `Though A, B`または`B though A`は「確かにAだがB」。Aは前置きで、Bが伝えたい内容となる。 |
| whether ～ (or not) | [Try IT同単元のポイント](https://www.try-it.jp/chapters-4047/lessons-4080/) | `whether A (or not), B`または`B whether A (or not)`は「AであってもなくてもB」。 |
| 読解時の予測 | [Try IT同単元の練習](https://www.try-it.jp/chapters-4047/lessons-4080/practice-2/) | though節の後ろには前置きと反対・対照的な内容、whether ～ or not節の後ろには話者が主張したい内容が続く。 |

## ノート作成時の適用基準

though/although節、whether ～ (or not)節を見つけたら、そこを前置き・条件にかかわらない部分として把握する。後ろまたは前に置かれた主節のうち、話者が最も伝えたい結論を探す。
