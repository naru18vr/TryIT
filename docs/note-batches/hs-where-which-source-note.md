# 高校英語文法「whereとwhichの使い分け」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| whereの条件 | [Try IT「whereとwhichの使い分け」](https://www.try-it.jp/chapters-3978/lessons-4003/) | 場所を表す先行詞であっても、`前置詞 + which`にできる場合だけwhereに置き換えられる。 |
| whichの条件 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-4003/) | `visit the place`のように先行詞が動詞の目的語で前置詞を必要としない場合はwhichを使い、whereには置き換えられない。 |
| 判別手順 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3978/lessons-4003/practice-2/) | 場所の名詞の後は、(1)which、(2)前置詞＋which、(3)whereの順に元の文の構造から判定する。 |

## 対象動画

静的カタログから、正規動画 `4FPLMqLSedw`（whereとwhichの使い分け①）と `2AW8vxdkJJw`（whereとwhichの使い分け②）を確認した。

## ノート作成時の適用基準

先行詞が場所を表すかだけでは判断せず、元の文に戻す。先行詞が動詞の目的語ならwhich、前置詞＋whichになるならwhereへの置き換えが可能である。
