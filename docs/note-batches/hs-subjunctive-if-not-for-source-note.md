# 高校英語文法「If it were not for などの表現」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 現在についての仮定 | [Try IT「If it were not for などの表現」](https://www.try-it.jp/chapters-3856/lessons-3885/) | `If it were not for＋名詞` は「もし名詞がなければ」で、現在の仮定法過去を表す。 |
| 過去についての仮定と言い換え | [Try IT同単元の練習](https://www.try-it.jp/chapters-3856/lessons-3885/practice-2/) | `If it had not been for＋名詞` は「もし名詞がなかったならば」。どちらもWithout／But for＋名詞で言い換えられる。 |
| If省略による倒置 | [進研ゼミ高校講座「Had it not been for」](https://benesse.jp/kyouiku/teikitest/kou/english/english/k00121.html) | `Had it not been for ...` はifを省略して倒置した表現で、`If it had not been for ...` と同じ意味。 |

## ノート作成時の適用基準

「名詞がなければ」を表す定型表現は、現在ならwere not for、過去ならhad not been forと時制を区別する。Without／But forは名詞句を続ける前置詞表現であり、単に形を丸暗記せず、続く主節が現在・過去のどちらについての反事実かも確かめる。Had it not been forの倒置形は質問文と誤認しないように扱う。
