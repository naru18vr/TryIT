## ノートに反映する確認済み事項

Try IT公式は、条件を表す接続詞として **if** 「もし～ならば」、**unless** 「もし～ないならば」、**once** 「いったん～すると」を扱っている。unlessは語自体に否定の意味を含むため、unlessの後ろを肯定形にして重ねて `not` を置かない。onceは副詞なら「かつて」だが、`once + 主語 + 動詞` の形では条件の接続詞として「いったん主語が～すると」を表す。

練習ページでは、`once + 主語 + 動詞` を見て副詞の「かつて」と誤認しないこと、unlessが否定の意味を含むことを確認できる。ノートでは個別の設問の文言・解答を転記せず、これらの一般化できる文法規則、選択手順、誤りやすい点、復習観点を学習用に整理する。
