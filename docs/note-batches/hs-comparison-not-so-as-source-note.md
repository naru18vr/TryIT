# 高校英語文法「～ほど…でない（not so … as ～）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 基本形 | [Try IT「～ほど…でない」の表現](https://www.try-it.jp/chapters-3897/lessons-3954/) | `not so … as ～`で「～ほど…でない」。as／so … asの否定形として使う。 |
| soを使う理由 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3897/lessons-3954/) | 否定ではnotを置くだけでなく、1つ目のasをsoへ変える。`not so rich as you`。 |
| 読み方・語順 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3897/lessons-3954/practice-2/) | notとso … asが離れることがあり、`can't play the piano so well as Carol`もnot so … asの意味として読む。「同じくらい高くない」とは訳さない。 |

## ノート作成時の適用基準

not so … asは「比較対象ほど程度が高くない」という比較であり、単純な否定と混同しない。形容詞・副詞またはmany booksのようなかたまりをsoとasの間へ置く。notの位置が助動詞などで離れていても、so … asと一組にして判断する。
