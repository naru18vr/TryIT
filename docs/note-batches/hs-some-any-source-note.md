## ノート作成に反映する確認済み事項

* someは主に肯定文で使う。
* anyは主に否定文・疑問文で使う。
* someとanyは数えられない名詞にも使える。
* `not any`は「誰も〜ない／少しも〜ない」の強い打消しを表す。
* 条件文では肯定の節でもanyを使えることがある。
* 条件節と主節を別に見て、anyとsomeを選ぶ。
