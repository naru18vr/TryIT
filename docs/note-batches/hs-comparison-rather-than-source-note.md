# 高校英語文法「AというよりはむしろB」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 二つの基本形 | [Try IT「AというよりはむしろB」の表現](https://www.try-it.jp/chapters-3897/lessons-3970/) | `not so much A as B`と`B rather than A`は、いずれも「AというよりはむしろB」。 |
| 重要内容の位置 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3897/lessons-3970/) | `not so much A as B`ではBが後ろ、`B rather than A`ではBが前に来る。 |
| 相互の書き換え | [Try IT同単元の練習](https://www.try-it.jp/chapters-3897/lessons-3970/practice-2/) | `This is not so much a novel as a poem.`は`This is a poem rather than a novel.`へ言い換えられる。 |

## ノート作成時の適用基準

どちらの形でも本当に伝えたい内容はBである。as／thanの前後にある名詞・形容詞などをA・Bとして対応させ、not so muchの否定を単独で処理せず、文全体を「AというよりB」と読む。
