# 高校英語文法「関係代名詞whatの使い方1」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| whatの意味 | [Try IT「関係代名詞whatの使い方1」](https://www.try-it.jp/chapters-3978/lessons-4023/) | whatは「～こと・もの」を表し、`the thing(s) which`と同じ意味のかたまりを作る。 |
| 名詞を含む構造 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-4023/) | whichは名詞の後に置くが、whatは名詞の意味を含むため文頭など名詞の後以外にも置ける。 |
| 読み方・書き換え | [Try IT同単元の練習](https://www.try-it.jp/chapters-3978/lessons-4023/practice-2/) | `what I said`を「私が言ったこと」とひとかたまりで読み、`the thing(s) which I said`へ書き換えて確認できる。 |

## 対象動画

静的カタログから、正規動画 `QCORJje1DaA`（関係代名詞what①）と `McsNWJViixE`（関係代名詞what②）を確認した。高校英語構文の同名動画は指定順に従い対象外とする。

## ノート作成時の適用基準

what以下を「～こと・もの」の名詞相当のかたまりとして捉える。whatの直前にthe thingなどの先行詞を置かず、必要に応じてthe thing(s) whichへ書き換えて意味と構造を確認する。
