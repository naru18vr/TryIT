## ノートに反映する確認済み事項

Try IT公式は、接続詞 `that` が「文そのもの」を名詞のかたまりである名詞節にし、そのthat節が主語、目的語、補語になれることを扱っている。that節が主語になる場合には、文頭が長くなるのを避けるため、形式主語 `it` を文頭に置き、内容を表すthat節を後ろに置く形が多い。that節が目的語・補語になる場合には、通常、動詞やbe動詞の後ろに置く。

練習ページでは、目的語となるthat節ではthatが省略されることが多いこと、補語のthat節はthatから節の終わりまでを一つのまとまりとして捉えることを確認できる。補助資料も、主語のthat節は形式主語itを用いる形が一般的であると説明している。ノートでは個別設問の文言・解答は転記せず、一般化できる役割の判定、節の範囲、省略の見分け方、復習観点を学習用に整理する。
