## ノート作成に反映する確認済み事項

* 仮目的語のitは特定の物を指さず、後ろのto Vまたはthat節が表す内容を仮に受ける。
* `find it 形容詞 to V`は「Vするのは形容詞だと分かる」、`think it 形容詞 to V`は「Vするのは形容詞だと思う」を表す。
* `make it 形容詞 to V`と`make it a rule to V`は、to Vで表す事柄をどうするかを述べる。
* `take it for granted that S V`ではthat節がitの内容である。
* `not to V`ではnotをto Vの意味のかたまりに含めて考える。
