## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| becauseとsinceの基本 | [Try IT「理由を表す接続詞」](https://www.try-it.jp/chapters-4047/lessons-4076/) | becauseとsinceはいずれも理由を表す接続詞である。 |
| 置く位置と理由の重さ | [Try IT同単元のポイント](https://www.try-it.jp/chapters-4047/lessons-4076/) | becauseは基本的に文の後ろに置き、しっかり理由を述べる。sinceは文頭にも置け、軽く理由を添えられる。 |

## ノート作成時の適用基準

理由そのものを強調して伝えるならbecauseを文後半で、前提として軽く添えるならsinceを文頭で使う。`since`には時の「～以来」の用法もあるため、理由を述べているか、時間の起点を表しているかを文脈と主節の時制で確認する。
