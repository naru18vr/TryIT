# 高校英語文法「時を表す接続詞3（timeを用いた表現）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| timeを用いる接続詞句 | [Try IT「timeを用いた表現」](https://www.try-it.jp/chapters-4047/lessons-4072/) | `by the time`、`every time`、`next time`は、timeの後ろに主語＋動詞を続けて接続詞のかたまりとして用いる。 |
| by the timeとuntil | [Try IT同単元のポイント](https://www.try-it.jp/chapters-4047/lessons-4072/) | `by the time`は「～するまでに」で期限を表す。`until`は「～までずっと」で継続を表すため区別する。 |
| every time・next time | [Try IT同単元の練習](https://www.try-it.jp/chapters-4047/lessons-4072/practice-2/) | `every time S+V`は「～するたびに」、`next time S+V`は「次に～する時に」を表す。 |

## 対象動画

公式ページの公開埋め込み情報を照合した後、静的カタログから、正規動画 `Y9_ZNICDE1g`（by the time などの表現①）と `Ef2kR4sWjio`（by the time などの表現②）を確認した。

## ノート作成時の適用基準

by the timeでは期限までに一度完了する動作、untilでは終点まで続く状態・動作を想定して区別する。every timeとnext timeはtimeの直後から主語＋動詞までを一つの接続詞句として捉える。
