# 高校英語文法「仮定法」導入ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 仮定法の基本 | [Try IT「仮定法」とは？](https://www.try-it.jp/chapters-3856/lessons-3857/) | 仮定法は、現実にはありえない内容を表す動詞の使い方。現在についての反事実的な内容は過去形で表す。 |
| 仮定法過去の基本形 | [Try IT「Ifを使った仮定法（仮定法過去）」](https://www.try-it.jp/chapters-3856/lessons-3865/) | `If＋主語＋過去形, 主語＋would/could＋動詞の原形` が基本。現在の反事実的な条件と結果を表す。be動詞はwereを用いる。 |
| 時制関係 | [進研ゼミ高校講座「仮定法過去完了と仮定法過去が混じった文」](https://benesse.jp/kyouiku/teikitest/kou/english/english/k00124.html) | 仮定法の種類は、いつの事実に反する仮定かで判定する。過去の反事実ならif節はhad＋過去分詞を用いる。 |

## ノート作成時の適用基準

仮定法は単に「仮のこと」ではなく、現実と異なる内容を距離を置く時制で表す用法として説明する。導入動画では、現在の内容に過去形を使う理由、直説法との対比、will/canとwould/couldの対比を中心に扱い、過去の反事実的内容は後続の仮定法過去完了の動画で区別する。
