# 高校英語文法「時を表す接続詞2（before / after / since / until）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| before・after | [Try IT「before / after / since / until」](https://www.try-it.jp/chapters-4047/lessons-4068/) | beforeとafterは時間の順序が反対で、beforeは「～する前に」、afterは「～した後に」を表す。 |
| since | [Try IT同単元のポイント](https://www.try-it.jp/chapters-4047/lessons-4068/) | sinceは「～して以来」を表し、節の外側の主節では完了形が使われることが多い。起点を示す。 |
| until | [Try IT同単元のポイント・練習](https://www.try-it.jp/chapters-4047/lessons-4068/practice-2/) | until/tillは「～するまでずっと」を表し、継続の終点を示す。sinceの起点と区別する。 |

## 対象動画

Try IT公式検索結果の動画と静的カタログを照合し、正規動画 `HRvyvOKULPk`（before/after/since/until①）と `5eGl7MKpYNs`（before/after/since/until②）を確認した。公式レッスンページが公開する埋め込みIDはカタログに存在しなかったため、カタログに登録済みの正規YouTube動画IDとタイトルによって対象を確定した。

## ノート作成時の適用基準

出来事の順序を矢印で整理してbeforeとafterを選ぶ。継続表現では、始まりを示すsinceと終わりを示すuntil/tillを混同しない。since節と主節の時制を確認し、完了形との組み合わせを見落とさない。
