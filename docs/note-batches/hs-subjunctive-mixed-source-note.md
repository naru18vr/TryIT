# 高校英語文法「仮定法過去完了＋仮定法過去」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 混合仮定法の意味 | [Try IT「仮定法過去完了＋仮定法過去」](https://www.try-it.jp/chapters-3856/lessons-3881/) | 過去の反事実的条件と、現在の反事実的結果を同じ文で表す。 |

| 時制を節ごとに判断する基準 | [進研ゼミ高校講座「仮定法過去完了と仮定法過去が混じった文」](https://benesse.jp/kyouiku/teikitest/kou/english/english/k00124.html) | if節と主節がそれぞれいつの事実に反するかで、過去完了形・過去形を選ぶ。 |

## ノート作成時の適用基準

混合仮定法では、文全体の時制をそろえるのではなく、if節は過去の反事実、主節は現在の反事実というように節ごとに判断する。now・then・in my youthなどの時を表す語を手掛かりにし、過去の出来事が現在の状態に影響している因果関係を日本語で整理してから英文の形を選ぶよう説明する。
