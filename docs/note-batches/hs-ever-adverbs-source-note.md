# 高校英語文法「whenever・wherever・howeverの使い方」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| whenever・wherever | [Try IT「whenever、wherever、howeverの使い方」](https://www.try-it.jp/chapters-3978/lessons-4039/) | wheneverは「いつでも」、whereverは「どこでも」を表し、時・場所を表す副詞的なかたまりを作る。 |
| howeverの形 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-4039/) | howeverは単独でなく、後ろに形容詞または副詞を置き、「たとえどれほど～でも」を表す。 |
| 文中での働き | [Try IT同単元の練習](https://www.try-it.jp/chapters-3978/lessons-4039/practice-2/) | wherever／wheneverは、主節の動詞を時・場所の面から修飾する副詞節として用いられる。 |

## 対象動画

静的カタログから、正規動画 `F0MXW8rW8Oc`（whenever/wherever/however①）と `KJzeL63bUpk`（whenever/wherever/however②）を確認した。

## ノート作成時の適用基準

-everを「～でも」の意味として捉え、wheneverは時、whereverは場所の副詞節と判定する。howeverは必ず形容詞・副詞を後ろに伴う形で使う点を明示する。
