## ノートに反映する確認済み事項

Try IT公式は、名詞節を導く `whether` と `if` がともに「～かどうか」を表すが、**whetherは主語・補語・目的語に使えるのに対し、ifは一般動詞の目的語に限られる**と整理している。したがって、文頭の主語、be動詞の後ろ、`or not` を伴う形ではwhetherを使い、一般動詞の後ろで目的語になる場合はwhetherとifのどちらも使える。

練習ページでは、`whether + 主語 + 動詞 + or not`、`ask 人 if + 主語 + 動詞`、名詞節のifと条件のifの区別を確認できる。名詞節のifは後ろに未来を表すwillを取ることがあり、条件のif節では未来のことでも現在形を用いるという違いが、訳と構造を判定する手がかりになる。補助資料も、ifが主語・補語・前置詞の目的語には使えず、whetherの方が広く使えると説明している。ノートでは個別設問の文言・解答は転記せず、一般化できる配置の判定、or not、条件ifとの区別、復習観点を学習用に整理する。
