# 高校英語文法「時を表す接続詞1（whenとwhileの違い）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| whenとwhileの基本 | [Try IT「whenとwhileの違い」](https://www.try-it.jp/chapters-4047/lessons-4064/) | `when`は「～するとき」、`while`は「～する間」を表す。whileの節では主に進行形が使われる。 |
| whileの対比用法 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-4047/lessons-4064/) | `while`には時の「～する間」だけでなく、対比を表す「一方」の用法がある。 |
| 接続詞節の省略 | [Try IT同単元の練習](https://www.try-it.jp/chapters-4047/lessons-4064/practice-2/) | 主節と接続詞節の主語が同じ場合、when/whileの後ろの主語＋be動詞が省略できる。`while ～ing`はその代表的な形。 |

## 対象動画

公式ページの公開埋め込み情報を照合した後、静的カタログから、正規動画 `OhLdBHQNS94`（whenとwhileの違い①）と `zQ9owQC8mlY`（whenとwhileの違い②）を確認した。

## ノート作成時の適用基準

時の表現では、瞬間・時点を表すか、進行中の期間を表すかを確認する。whileは対比を表す可能性もあり、文の前後が二つの性質や行動を対照させているかで判断する。省略形は主語を復元して意味を確かめる。
