## ノートに反映する確認済み事項

Try IT公式は、代表的な数えられない名詞を、物質名詞と集合名詞に分けている。物質名詞は決まった形がないため数えられず、bread、glass、paperなどは冠詞や複数形のsを付けない。集合名詞は集まりを漠然と表し、luggage／baggageやfurnitureも冠詞や複数形のsを付けない。

練習ではfurnitureとbaggage、チャレンジではluggageを確認し、someとa lot ofが数えられる名詞・数えられない名詞のどちらにも付けられることを扱う。ノートでは個別の設問・解答を転記せず、名詞の分類、冠詞・複数形、量表現を復習観点として整理する。
