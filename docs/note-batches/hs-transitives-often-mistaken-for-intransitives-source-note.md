## ノートに反映する確認済み事項

Try IT公式は、`leave`、`reach`、`oppose`、`attend`を、目的語を直接取るため前置詞を置かない他動詞として扱っている。授業で確認した形は、`leave ～`、`reach ～`、`oppose ～`、`attend ～`である。

練習・チャレンジでは、`reach ～`と`arrive in/at ～`のような言い換え、`oppose ～`と`agree with ～`の違いを扱う。ノートでは個別の設問文・解答を転記せず、他動詞には前置詞が不要である根拠、日本語の「～から」「～に」に引きずられて不要な前置詞を足さない注意点、復習観点を学習用に整理する。
