# 高校英語文法「関係副詞の使い方2（why・how）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| whyの表現 | [Try IT「関係副詞の使い方2」](https://www.try-it.jp/chapters-3978/lessons-4007/) | `This/That is why ...`は「こういうわけで…」を表す。whyはreasonを説明する関係副詞である。 |
| howの表現 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-4007/) | `This/That is how ...`は「こうやって…」を表す。howはwayを説明する関係副詞である。 |
| 名詞との併用 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3978/lessons-4007/practice-2/) | `the reason why`は強調として残せる場合がある。一方、`the way how`は使わず、`the way`または`how`のどちらかを用いる。 |

## ノート作成時の適用基準

`This is why`と`This is how`を定型表現として区切り、後ろに理由・方法の中心内容が続くと読む。reasonとwhy、wayとhowを重複させないかを確認する。
