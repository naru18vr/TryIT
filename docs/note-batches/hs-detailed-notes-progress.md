# 高校課程・詳しい学習ノート整備の進捗

## 方針

高校課程のカタログは学年別ではなく「高校」として登録されているため、動画タイトルに示された科目・単元の履修順を確認し、数学I・各基礎科目など高校1年相当の内容から順に整備する。各ノートは、正規動画タイトルと公的機関または教育機関の一次資料を照合して作成し、要約には考え方・手順・理由・よくある間違いを、覚えるポイントには必ず「復習では」から始まる確認観点を含める。
