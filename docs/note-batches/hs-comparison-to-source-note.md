## ノート作成時の適用基準

通常の比較級にはthanを用いるが、superior、inferior、senior、juniorはtoを用いる特別な比較級として扱う。語尾iorを手掛かりにしつつ、語ごとの意味と後続前置詞を組で覚える。superior thanやsenior thanのようにthanを置かない。
