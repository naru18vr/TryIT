## ノートに反映する確認済み事項

Try IT公式は、`regard A as B`を「AをBと見なす」、`refer to A as B`を「AをBと呼ぶ」、`talk A into Ving`を「Aを説得して～させる」としている。`as`はAとBのイコール関係、`into`はAがVingへ変化するイメージを表す。

練習では、`regard A as B`のBに形容詞も置けること、`talk A into Ving`ではintoの後ろが動名詞になることを確認する。チャレンジでは、`refer to A as B`と受動態の日本語を能動態の英語へ組み替える視点を確認する。ノートでは個別の設問・解答を転記せず、A・as・BおよびA・into・Vingの語順、各前置詞の意味を復習観点として整理する。
