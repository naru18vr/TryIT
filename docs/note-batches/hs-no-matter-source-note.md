# 高校英語文法「no matter ～，の使い方」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| no matterの意味 | [Try IT「no matter ～，の使い方」](https://www.try-it.jp/chapters-3978/lessons-4043/) | `no matter ～,`は「たとえ～でも」を表し、後ろをカンマで区切る。 |
| 複合関係詞との対応 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-4043/) | `no matter who/what/when/where,`は`whoever/whatever/whenever/wherever,`と対応し、`no matter how＋形容詞,`は`however＋形容詞,`と対応する。 |
| カンマの重要性 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3978/lessons-4043/practice-2/) | 複合関係詞の後ろにカンマがあると譲歩の「たとえ～でも」となり、カンマがない名詞節・副詞節の用法と区別する。 |

## 対象動画

静的カタログから、正規動画 `tw89cCoh90o`（no matter ～，の使い方①）と `OCUrPVN0RZE`（no matter ～，の使い方②）を確認した。

## ノート作成時の適用基準

no matterの後に来る疑問詞とカンマを一組で捉え、譲歩節として読む。複合関係詞と書き換えるときは、カンマの有無により意味・文中の役割が変わることを明示する。
