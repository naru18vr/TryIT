# 高校英語文法「最上級（the-est／the most）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 最上級の基本 | [Try IT「最上級（the-est / the most ～）」の表現](https://www.try-it.jp/chapters-3897/lessons-3930/) | 3つ以上の対象を比べて「（…の中で）最も～」を表す。短い語はthe＋-est、長い語はthe most＋原級。 |
| 語形とthe | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3897/lessons-3930/) | bigは子音を重ねてthe biggest。副詞の最上級にはtheを付けないことが多い。 |
| 範囲・省略・one of | [Try IT同単元の練習](https://www.try-it.jp/chapters-3897/lessons-3930/practice-2/) | in／ofで比較範囲を表す。one of the 最上級＋複数名詞は「最も～なものの一つ」。 |

## ノート作成時の適用基準

最上級を見たら、第一に比較対象が3つ以上であること、第二にin／ofで比較範囲が示されていることを確かめる。短い語はthe＋-est、長い語はthe most＋原級を用い、同じ内容の名詞が省略される場合がある。one of the 最上級の後ろは複数名詞にする。
