# 高校英語文法「関係代名詞as・but・than」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 関係代名詞as | [Try IT「関係代名詞のas/but/than」](https://www.try-it.jp/chapters-3978/lessons-4031/) | `such 名詞 as ...`は「…するような名詞」、`the same 名詞 as ...`は「…と同じ名詞」を表す。 |
| 関係代名詞but | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-4031/) | `There is no 名詞 but ...`は「…しない名詞はない」を表す。noの代わりにfewなど否定的な語でも同じ考え方を用いる。 |
| 関係代名詞than | [Try IT同単元の練習](https://www.try-it.jp/chapters-3978/lessons-4031/practice-2/) | `more 名詞 than ...`は「…よりも多くの名詞」を表し、比較の意味を含むthanが後続節で関係代名詞的に働く。 |

## 対象動画

静的カタログから、正規動画 `xpTKUScYDvA`（関係代名詞 as/but/than①）と `DsYLvwXEdPM`（関係代名詞 as/but/than②）を確認した。

## ノート作成時の適用基準

as・but・thanを単なる接続詞・前置詞として判断せず、such・the same・否定表現・moreなどの前方の合図と組にして判定する。定型全体を覚え、後ろに述語を導く関係代名詞的な役割を確認する。
