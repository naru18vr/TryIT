## ノート作成に反映する確認済み事項

* toは相手に確実に届くことを表す。
* forは相手のために向かうが、届くとは限らないことを表す。
* `buy/make/get/find + 物 + for + 人`、`give/teach/show/send + 物 + to + 人`を扱う。
* `bound for ～`、`bring A to B`、`leave for A`を扱う。
