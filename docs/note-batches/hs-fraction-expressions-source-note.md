## ノートに反映する確認済み事項

Try IT公式は、英語の分数を「分子は基数、分母は序数」の順に表すと説明する。`one-third`に対し、分子が2以上なら分母を複数形にして`two-thirds`、`four-fifths`とする。`a half`は2分の1、`a quarter`は4分の1を表し、`one and a half`は1と2分の1、すなわち1.5を表す。

ノートでは、分母・分子を日本語の「〜分の〜」と逆に取り違えないこと、分子が2以上のときの分母の複数形、特別表現を復習観点として整理する。個別の設問・解答は転記しない。
