# 高校英語文法「関係代名詞1（主格）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 関係代名詞の役割 | [Try IT「関係代名詞1」](https://www.try-it.jp/chapters-3978/lessons-3979/) | 関係代名詞は直前の名詞に、後ろから説明のかたまりを付け加える。 |
| 人・物の区別 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-3979/) | 人には`who`、物には`which`を使い、「その人が～」「その物が～」と直前の名詞を受ける。 |
| 読み取り | [Try IT同単元の練習](https://www.try-it.jp/chapters-3978/lessons-3979/practice-2/) | 主格の関係詞節には動詞が一つ含まれる。who／whichから動詞を含むかたまりを区切り、先行詞を後ろから説明すると読む。 |

## 対象動画

静的カタログから、正規動画 `5gNZkNjJbvk`（関係代名詞1 主格①）と `bCjx8ck1v3s`（関係代名詞1 主格②）を確認した。

## ノート作成時の適用基準

先行詞が人ならwho、物ならwhichを選ぶ。関係詞節内ではwho／whichが主語の役割を持つので、動詞の前に別の主語を重ねない。先行詞と関係詞節をひとまとまりにし、後ろから日本語へ読み下す。
