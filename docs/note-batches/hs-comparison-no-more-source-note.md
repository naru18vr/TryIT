# 高校英語文法「no more … than など」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| no more … than | [Try IT「no more … than などの表現」](https://www.try-it.jp/chapters-3897/lessons-3914/) | `no more … than ～` は「～と同じく…ではない」を表す。than前が述べたい内容、than後が具体例となる。 |
| no less … than | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3897/lessons-3914/) | `no less … than ～` は「～と同じく…である」を表す。 |
| 言い換えと読み方 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3897/lessons-3914/practice-2/) | no moreはnot any moreに言い換えられる。thanより前後を区切り、後半を具体例として読む。 |

## ノート作成時の適用基準

no more … thanは単純な数量比較ではなく、than前の否定内容をthan後の例と同じだと強調する表現である。no less … thanは肯定内容を強調する。訳す前にthan前を「主張」、than後を「比較に使う具体例」に分け、肯定・否定の向きを判断する。
