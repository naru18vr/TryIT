## ノートに反映する確認済み事項

Try IT公式は、`stand`が目的語を取ると「～を我慢する」、`miss`が「～を失う」から派生して「～がいなくて寂しく思う」、`have a + 動作を表す名詞`が一つの動詞相当の表現になることを扱っている。`have a chat`や`have a look`のように、`have`の後ろの名詞が表す動作に応じて意味を決める。

練習では目的語の存在から`stand`の意味を「立つ」ではなく「我慢する」と判定し、`miss`の文脈上の意味を判定する。チャレンジでは`have a chat`の冠詞`a`を含む定型を確認する。ノートでは個別の設問文・解答を転記せず、目的語・定型表現・文脈から用法を判定する復習観点を学習用に整理する。
