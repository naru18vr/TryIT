# 高校英語文法「X番目に～だ」「もっとも～でない」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| X番目の最上級 | [Try IT「X番目に～だ」「もっとも～でない」の表現](https://www.try-it.jp/chapters-3897/lessons-3938/) | `the second largest` のように、theと最上級の間へ序数を入れる。「一番目」はthe first largestではなくthe largest。 |
| もっとも～でない | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3897/lessons-3938/) | `the least＋形容詞` が「もっとも～でない」。`not the most＋形容詞` は「もっとも～というわけではない」で別の意味。 |
| 文中での確認 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3897/lessons-3938/practice-2/) | the second largest cityとthe least useful dictionaryの位置・意味を確認できる。 |

## ノート作成時の適用基準

序数はtheと最上級の間に置き、the second／third／fourth＋最上級の形を使う。最上級の否定的な意味を「最も～でない」と表すときはthe leastを使い、not the mostと混同しない。最上級表現の後ろに置く名詞と、比較範囲を表すof／inも確認する。
