## ノート作成に反映する確認済み事項

* `It seems that S V`は、ある内容について「…のように思われる」と判断・推測を表す。
* `It happens that S V`は、偶然にその出来事が起こることを表す。
* 現在形のseemsには三単現のsを付け、過去の出来事を述べる場合はhappenedを用いる。
* `It seems that ...`のthatは省略でき、`It seems like ...`でも「…のようだ」を表せる。
* itが複数ある文では、構文上のitと天候・気候を表すitなど、文中での役割を分けて判断する。
