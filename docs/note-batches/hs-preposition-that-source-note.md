## ノートに反映する確認済み事項

Try IT公式は、前置詞の後にthat節が来る定型表現として、**in that + 主語 + 動詞**「～という点で」と、**except that + 主語 + 動詞**「～という点を除いて」を扱っている。that以下は一つの名詞のかたまりと考え、前置詞＋名詞に相当する構造として捉える。どちらも形と意味をセットで覚える。

練習・チャレンジページでは、in that節が前の内容についての相違点・理由などの具体的な観点を補うこと、except that節が例外となる内容を示すこと、選択肢の余りを手がかりにせず意味と構造から定型表現を選ぶことを確認できる。ノートでは個別設問の文言・解答は転記せず、定型表現の意味、節の範囲、文脈による選択、復習観点を学習用に整理する。
