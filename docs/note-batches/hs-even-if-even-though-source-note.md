# 高校英語文法「譲歩を表す接続詞2（even if / even though）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| even if・even thoughの基本 | [Try IT「譲歩を表す接続詞2」](https://www.try-it.jp/chapters-4047/lessons-4084/) | `even if`は「たとえもし～でも」、`even though`は「確かに～だが」を表す。 |
| 仮定と事実の区別 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-4047/lessons-4084/) | 未来など実際に起こっていない仮定への譲歩ならeven if、実際にあった事実への譲歩ならeven thoughを用いる。 |
| 文脈による判断 | [Try IT同単元の練習](https://www.try-it.jp/chapters-4047/lessons-4084/practice-2/) | `even though it was bad weather`は事実、`even if you don't like to`は仮定を表す。 |

## 対象動画

公式ページの公開埋め込み情報を照合した後、静的カタログから、正規動画 `e8QDO-D1SbE`（even if / even though①）と `9R2S2xJTSZk`（even if / even though②）を確認した。

## ノート作成時の適用基準

譲歩節が現実に起きた事実か、これから起こる可能性などの仮定かを最初に判断する。evenは強調の働きを持ち、省略されることもあるが、ifとthoughの選択は仮定・事実で決める。
