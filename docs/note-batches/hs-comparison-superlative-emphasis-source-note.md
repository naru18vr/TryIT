# 高校英語文法「最上級の強調」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| by far | [Try IT「最上級（the-est / the most ～）の強調」](https://www.try-it.jp/chapters-3897/lessons-3934/) | `by far` を最上級のtheの前に置くと、「はるかに／ずば抜けて一番～」を表す。 |
| 副詞の最上級 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3897/lessons-3934/) | 副詞の最上級にはtheを付けないのが基本で、`by far fastest` のように表す。 |
| the very | [Try IT同単元の練習](https://www.try-it.jp/chapters-3897/lessons-3934/practice-2/) | `the very best` のようにtheと最上級の間にveryを置き、by far the bestと同様に強調できる。 |

## ノート作成時の適用基準

最上級の強調では、by farをtheの前に置くのに対し、veryはtheの直後に置く。副詞最上級でtheがない場合も、by farは最上級の前に置ける。比較級を強調するmuchやfarと、最上級を強調するby far／the veryの位置を混同しない。
