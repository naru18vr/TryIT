## ノート作成時の適用基準

最上級を原級へ書き換えるときは否定主語＋so＋原級＋as、比較級へ書き換えるときは否定主語＋比較級＋thanを使う。NothingまたはNo other名詞が否定を担うため、比較級・原級の文でも最上級相当の意味になることを明記する。
