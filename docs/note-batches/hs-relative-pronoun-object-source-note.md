# 高校英語文法「関係代名詞3（目的格）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 目的格の関係代名詞 | [Try IT「関係代名詞3」](https://www.try-it.jp/chapters-3978/lessons-3987/) | 先行詞が人で「その人を～」と説明する場合はwhom、物で「その物を～」と説明する場合はwhichを用いる。 |
| 前置詞を伴う形 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-3987/) | 元の文の目的語をwhomに置き換えると、動詞に付いていた前置詞は節内に残る。 |
| 目的格の省略 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3978/lessons-3987/practice-2/) | 「人を～」「物を～」と説明する目的格のwhom・whichは省略できる。省略されても、関係詞節が先行詞を後ろから説明する働きは変わらない。 |

## 対象動画

静的カタログから、正規動画 `wIScHyIayzQ`（関係代名詞3 目的格①）と `jVCUaTe9kmo`（関係代名詞3 目的格②）を確認した。

## ノート作成時の適用基準

関係詞節内で先行詞が動詞または前置詞の目的語になっているかを確認する。人にはwhom、物にはwhichを置き、目的格が省略された場合も補って節の範囲と主節を判別する。
