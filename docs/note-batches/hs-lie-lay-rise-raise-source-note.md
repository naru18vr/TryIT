## ノートに反映する確認済み事項

Try IT公式は、自分が横になることを表す自動詞`lie`と、何かを横にすることを表す他動詞`lay`、自分が上がることを表す自動詞`rise`と、何かを上げることを表す他動詞`raise`を対にして扱っている。主語自身の動きなら`lie`／`rise`、目的語へ働きかけるなら`lay`／`raise`を選ぶ。

練習では、`lay`が自動詞`lie`の過去形でもあること、`lay down`が「横になった」を表すこと、`raise`が目的語を取って「～を上げる」を表すことを確認する。チャレンジでは、目的語が直後にあるかを根拠に、自動詞`lie`の過去形`lay`と他動詞`lay`の過去形`laid`を区別する。ノートでは個別の設問文・解答を転記せず、主語自身か目的語かで判定する手順、`lie - lay - lain`と`lay - laid - laid`を混同しない復習観点を学習用に整理する。
