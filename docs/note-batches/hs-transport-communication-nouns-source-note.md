## ノートに反映する確認済み事項

Try IT公式は、交通手段を原則として`by + 無冠詞の名詞`（`by train`、`by ship`）で表し、通信手段も`by e-mail`のように表す。`by phone`は`on the phone`・`over the phone`とも言い換えられる。インターネットは`by/through the Internet`のように`the`を伴う例外である。人の車は所有格を伴うため`by`ではなく`in + 所有格 + car`とする。

ノートでは、冠詞の有無だけでなく、手段一般・人の所有物・電話・インターネットの別を復習観点として整理する。個別の設問・解答は転記しない。
