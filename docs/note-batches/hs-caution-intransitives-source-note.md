## ノートに反映する確認済み事項

Try IT公式は、`pay`が自動詞で「むくわれる・割に合う」、`sell`が自動詞で「売れる」、`read`が自動詞で「読める・（計器が）示す」、`last`が自動詞で「続く」を表すことを扱っている。これらは他動詞としての一般的な意味と異なるため、目的語があるか、主語自身の性質・状態・継続を述べているかを確認する。

練習・チャレンジでは、`sell well`、`read + 数値`、`last + 期間`、`pay`の「割に合う」の訳を確認する。ノートでは個別の設問文・解答を転記せず、自動詞用法の意味、受け身のように見える意味、文構造から判定する復習観点を学習用に整理する。
