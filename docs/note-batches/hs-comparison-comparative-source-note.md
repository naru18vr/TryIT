# 高校英語文法「比較級（-er／more）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 比較級の基本形 | [Try IT「比較級（-er / more ～）」の表現](https://www.try-it.jp/chapters-3897/lessons-3902/) | 2つの対象を比べて「より～」を表し、短めの語には-er、長めの語にはmoreを用いる。 |
| 比較対象 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3897/lessons-3902/practice-2/) | 「～より」はthan＋比較対象で表す。 |
| 語形判断と不規則変化 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3897/lessons-3902/practice-2/) | 発音する母音が2音以上ある語はmoreを用いる目安。good／wellはbetter、badはworseとなる。 |

## ノート作成時の適用基準

比較級は、まず比較対象が二つであることとthanの後ろを確かめ、形容詞・副詞の比較級を選ぶ。短い語は-er、長い語はmoreを基本とするが、語尾変化とbetter／worseなどの不規則変化は個別に確認する。moreと-erを重ねて使わない。
