## ノート作成に反映する確認済み事項

* eachは「それぞれの」を表し、`each of ...`の形を作れる。
* everyは「どの〜も全て」を表し、後ろにofを置けない。
* everyの後ろの普通の名詞は単数形にする。
* `every + 数詞 + 複数形`は「〜ごとに」を表す表現になる。
* everyの通常用法と「〜ごとに」の用法を区別する。
