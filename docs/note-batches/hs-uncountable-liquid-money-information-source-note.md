## ノートに反映する確認済み事項

Try IT公式は、液体・お金・情報を数えられない名詞として扱い、`a`などの冠詞を付けず、量を示すときに`much`・`little`を使うとしている。`some`、`a lot of`も数えられない名詞に付けられる。情報として扱われる`information`、`advice`、`news`は複数形にせず、不可算名詞は単数扱いなので、現在形の動詞は三人称単数形になる。

練習では、`some advice`と不可算名詞を主語にする現在形の動詞を確認する。チャレンジでは、`advice`に複数形のsや冠詞を付けず、`some good advice`とすることを確認する。ノートでは個別の設問・解答を転記せず、冠詞・複数形・量表現・単数扱いの動詞を復習観点として整理する。
