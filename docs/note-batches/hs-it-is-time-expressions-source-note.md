## ノート作成に反映する確認済み事項

* この`it`は時を表す代名詞であり、前にある特定の名詞を指す「それ」として訳さない。
* `It is + 時間 + since S V`では、`since`以下の出来事から現在までに経過した時間を表す。
* `It is + 時間 + before S V`では、`before`以下の出来事が起こるまでに必要な時間を表す。
* `not long before`は「長くない時間の後」を表すため、自然な日本語では「間もなく…した／する」となる。
* 時間を表す名詞・`since`・`before`・後ろのS Vという要素を分け、どちらの慣用表現かを判定してから文全体を訳す。
