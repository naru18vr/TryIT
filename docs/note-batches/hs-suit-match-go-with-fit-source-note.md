## ノートに反映する確認済み事項

Try IT公式は、服装などが人に似合うときに`suit`、物どうしの色などが調和するときに`match`または`go with`、服や靴のサイズ・型がぴったり合うときに`fit`を使うとしている。

練習では`fit`をサイズ・型、`match`を物どうしの調和として確認する。チャレンジでは、`match`が目的語を直接取るのに対し、`go with`は`go`と`with`の間に`well`のような副詞を入れられることを確認する。ノートでは個別の設問・解答を転記せず、「人・物・サイズ」のどれに関する適合かと、目的語を直接取るか`with`を伴うかから動詞を選ぶ復習観点を整理する。
