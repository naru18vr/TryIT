## ノート作成時の適用基準

仮定法過去完了は、過去の事実と反対の仮定・結果を表すことを主軸にする。if節のhad＋過去分詞と主節のwould/could＋have＋過去分詞を対応させ、had hadの一つ目と二つ目の役割も区別する。仮定法過去と混同しないため、条件と結果がいつの内容かを日本語で確かめてから形を選ぶ手順を示す。
