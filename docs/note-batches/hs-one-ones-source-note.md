## ノート作成に反映する確認済み事項

* one／onesは数えられる名詞の重複を避ける。
* 置き換える名詞が単数ならone、複数ならonesを使う。
* 形容詞が前にある場合、that／thoseではなくone／onesを使う。
* oneは特定されていない単数名詞を置き換え、特定された物を受けるitとは区別する。
* one／onesは数えられない名詞には使えない。
