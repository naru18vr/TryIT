# 高校英語文法「as if／as though＋仮定法」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 基本の意味 | [Try IT「as if(as though)＋仮定法」の表現](https://www.try-it.jp/chapters-3856/lessons-3889/) | as if／as thoughの後ろに仮定法を続けると「まるで～のように」を表す。 |
| 現在・同時の内容 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3856/lessons-3889/) | 基準となる出来事と同時の非現実的内容は、as if／as thoughの後ろを仮定法過去で表す。 |
| 前の時点の内容 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3856/lessons-3889/) | 基準となる出来事より前の非現実的内容は、as if／as thoughの後ろを仮定法過去完了で表す。 |
| 時制判断の手順 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3856/lessons-3889/practice-2/) | 前後で述べる内容が同時なら仮定法過去、時間のずれがあれば仮定法過去完了とする。 |

## ノート作成時の適用基準

「まるで～のように」を見たらas if／as thoughを確認し、前の節の出来事を基準に後ろの内容が同時か、それより前かを判定する。同時なら過去形、より前ならhad＋過去分詞を選ぶ。見かけの過去形だけで過去の出来事と決めず、二つの内容の時間関係を先に整理する。
