## ノートに反映する確認済み事項

Try IT公式は、目的語を直接取らない自動詞と、目的語を直接取る他動詞を、**目的語の前に前置詞が必要かどうか**で見分ける方法を扱っている。自動詞は目的語を直後に置けず、名詞を続けるために前置詞を伴う。他動詞は目的語を直後に置くため、前置詞を入れない。

公式のポイント・練習・チャレンジでは、`talk about`と`discuss`、`get married to 人`と`marry 人`、`go into`と`enter`、`look like`と`resemble`のように、意味が近くても前置詞の有無が異なる表現を扱う。ノートでは個別問題の文言・解答は転記せず、目的語・前置詞・言い換えの考え方、`discuss about`のような典型的な誤り、復習観点を学習用に整理する。
