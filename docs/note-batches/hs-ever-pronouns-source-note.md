# 高校英語文法「whoever・whichever・whateverの使い方」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| -everの意味 | [Try IT「whoever、whichever、whateverの使い方」](https://www.try-it.jp/chapters-3978/lessons-4035/) | everが「～でも」の意味を添え、whoeverは「誰でも」、whicheverは「どれでも」、whateverは「何でも」を表す。 |
| whicheverとwhatever | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-4035/) | 選択肢が限られた範囲ならwhichever、限定のない広い範囲ならwhateverを用いる。 |
| 文中での役割 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3978/lessons-4035/practice-2/) | whoever等で始まる部分は名詞相当のかたまりとなり、主語・目的語などになる。 |

## ノート作成時の適用基準

-everで始まる節を前の名詞にかける説明ではなく、名詞相当のまとまりとして読む。人・限定選択肢・限定のない対象の違いからwhoever／whichever／whateverを選ぶ。
