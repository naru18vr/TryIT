## ノートに反映する確認済み事項

Try IT公式は、**同格のthat** を直前の抽象名詞の内容を名詞節で具体化する接続詞として扱い、直前の名詞とthat節がイコールの関係にあると説明している。`fact`、`rumor`、`news`、`hope` などが前に来ることが多く、「that節という名詞」と訳すと関係が捉えやすい。

同格のthatと関係代名詞which／thatの区別では、that節の内部が主語・動詞・必要な目的語などを備えた完全な文になっているかを確認する。同格のthat自体は後ろの節で代名詞として働かない。一方、関係代名詞では関係詞が前の名詞の代わりをするため、後ろの節に主語・目的語などの欠けた要素が生じる。ノートでは個別設問の文言・解答は転記せず、一般化できるイコール判定、完全文かどうかの確認、誤りやすい点、復習観点を学習用に整理する。
