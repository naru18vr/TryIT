# 高校英語文法「等位接続詞and/or/but」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 等位接続詞の基本 | [Try IT「等位接続詞（and / or / but）」](https://www.try-it.jp/chapters-4047/lessons-4048/) | and・or・butは前後に同じ種類の要素を並べる。単語・句・節・文を並列できる。 |
| 基本の意味 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-4047/lessons-4048/) | andは「～と」、orは「～か／それとも」、butは「～だが」を表す。 |
| 並列構造の読み方 | [Try IT同単元の練習](https://www.try-it.jp/chapters-4047/lessons-4048/practice-2/) | 接続詞を見たら前後で何と何が並ぶかを確認し、動名詞同士や疑問文同士など同じ構造を確かめる。 |

## 対象動画

静的カタログから、正規動画 `Cy5Jm_5rIes`（等位接続詞 and/or/but①）と `synF6L96ZpA`（等位接続詞 and/or/but②）を確認した。

## ノート作成時の適用基準

接続詞だけを訳語で処理せず、前後の要素が単語・句・節・文のどの単位で対応しているかを確認する。繰り返しの主語・助動詞などが省略される場合も、元の並列構造へ戻して読む。
