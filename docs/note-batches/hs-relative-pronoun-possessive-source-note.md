# 高校英語文法「関係代名詞2（所有格）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| whoseの役割 | [Try IT「関係代名詞2」](https://www.try-it.jp/chapters-3978/lessons-3983/) | whoseは先行詞に「その人の～」「その物の～」という後ろからの説明を付け足す。 |
| 人・物への使用 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-3983/) | 人・物のいずれが先行詞でもwhoseを用いる。`whose + 名詞`を一まとまりで扱う。 |

## ノート作成時の適用基準

「人の～」「物の～」という所有関係を後ろから説明するときはwhoseを使う。who／whichとは異なり、whoseの直後に所有される名詞を置く。whose＋名詞から始まる関係詞節全体を先行詞にかかる説明として読む。
