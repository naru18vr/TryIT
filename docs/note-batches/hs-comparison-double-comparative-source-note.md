# 高校英語文法「比較級 and 比較級など」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 変化を表す定型表現 | [Try IT「比較級 and 比較級」などの表現](https://www.try-it.jp/chapters-3897/lessons-3910/) | `比較級 and 比較級` は「ますます～だ」を表す。 |
| 相関的な比較表現 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3897/lessons-3910/) | `The 比較級 ～, the 比較級 …` は「～すればするほど、ますます…」を表す。 |
| まとまりの読み方 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3897/lessons-3910/practice-2/) | `more and more beautiful` 全体で「ますます美しい」。`The sooner, the better.` は「早ければ早いほど良い」。 |

## ノート作成時の適用基準

比較級and比較級は、同じ比較級を繰り返して程度の変化を表す。moreの場合は`more and more＋形容詞／名詞`までを一まとまりとして読む。The比較級…, the比較級…では、二つのtheを定冠詞ではなく相関する構文の印として捉え、前半・後半の両方を比較級にする。
