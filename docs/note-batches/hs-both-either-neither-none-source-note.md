## ノート作成に反映する確認済み事項

* bothは2つのうち両方を表す。
* eitherは2つのうちどちらかを表す。
* neitherは2つのうちどちらも〜ないを表す。
* noneは3つ以上でどれも〜ないを表す。
* neitherとnoneはいずれも否定を含むため、対象の数で使い分ける。
