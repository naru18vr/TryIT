## ノート作成時の適用基準

`not more than`は「多くてもその数まで」なのでat most（せいぜい）、`not less than`は「その数より少なくない」のでat least（少なくとも）と対応させる。no more／no lessの比較構文とは別の熟語であるため、thanの前後を比べるのではなく、数量・程度を限定する表現として処理する。
