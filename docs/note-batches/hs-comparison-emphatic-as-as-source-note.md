# 高校英語文法「強調の as … as」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 強調の基本 | [Try IT「強調のas … as」](https://www.try-it.jp/chapters-3897/lessons-3962/) | as … asの形で「～も」という強調を表す。asとasの間に強調したい性質を置く。 |
| 数・回数・時期 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3897/lessons-3962/) | `as many as ～`は数、`as often as ～`は回数、`as early as ～`は早い時期を強調する。 |
| 語の選択 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3897/lessons-3962/practice-2/) | manyは数、muchは量。`as soon as`は未来の「すぐに」で、過去の時期を強調する`as early as`と区別する。 |

## ノート作成時の適用基準

これは同程度を比べるas … asとは異なり、数量・回数・早い時期を「～も」「早くも」と強める表現として読む。many／much、often、earlyを、強調する対象が数・量・頻度・時期のどれかで選ぶ。
