# 高校英語文法「分詞構文の否定形・完了形」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 否定形 | [Try IT「分詞構文の否定形・完了形」](https://www.try-it.jp/chapters-3807/lessons-3836/) | 否定形は `Not/Never + 分詞 ～, 主語＋動詞 …`。否定語を分詞句の先頭に置く。 |
| 完了形 | [Try IT同単元](https://www.try-it.jp/chapters-3807/lessons-3836/) | 完了形は `Having + 過去分詞 ～, 主語＋動詞 …`。分詞句の内容が主節より前に起こる関係を表す。 |
| 否定と完了の併用 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3807/lessons-3836/practice-2/) | `Never having + 過去分詞` のように、否定語を先頭に置いてから完了形を続ける。 |
| 過去の基準時点までの経験 | [進研ゼミ高校講座「完了形の分詞構文について」](https://kou.benesse.co.jp/nigate/english/a13e1404.html) | `Never having visited` は、主節の過去の時点までの経験を表す。現在完了ではなく、過去の基準時点との前後関係を示す。 |

## ノート作成時の適用基準

否定は `Not/Never` を分詞句の先頭へ置く。主節より前の出来事・経験・結果を明示する必要があるときは `Having + 過去分詞` を使い、否定と併用するときは `Never/Not having + 過去分詞` の順とする。通常の分詞構文でも時間関係が明白なら、むやみに完了形を使わない。
