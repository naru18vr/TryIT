# 高校英語文法「比較とは？」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 比較表現の三分類 | [Try IT「比較」とは？](https://www.try-it.jp/chapters-3897/lessons-3898/) | 比較には「～より」の比較級、「一番」の最上級、「同じくらい」のas ～ asの三つの基本パターンがある。 |
| 比較級と最上級 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3897/lessons-3898/) | `形容詞＋er＋than` は「～より…」、`the＋形容詞＋est` は「一番…」を表す。 |
| 原級比較とつづり | [Try IT同単元の練習](https://www.try-it.jp/chapters-3897/lessons-3898/practice-2/) | `as＋形容詞＋as` は「～と同じくらい…」。bigの比較級は末尾のgを重ねてbiggerとする。 |

## ノート作成時の適用基準

比較表現を見たら、比較級・最上級・原級比較のどれかを先に分類する。比較級ではthan、最上級では比較範囲を表すin／of、原級比較では二つ目のasの後ろの対象を確認する。語尾変化は機械的に覚えるだけでなく、比較対象と意味を対応させる。
