# 高校英語文法「同じくらい～（as ～ as）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 基本形 | [Try IT「同じくらい～（as ～ as）」の表現](https://www.try-it.jp/chapters-3897/lessons-3950/) | `as [so] ～ as ...`で「…と同じくらい～」。 |
| 間に置く語 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3897/lessons-3950/) | asとasの間には形容詞・副詞、またはそれらを含む意味のかたまりを置く。`as many books as I`のようにmany booksを切り離さない。 |
| 読解上の働き | [Try IT同単元の練習](https://www.try-it.jp/chapters-3897/lessons-3950/practice-2/) | `as beautiful as Venus`、`as well as Ichiro`のように具体例を置き、同程度比較で強調する。 |

## ノート作成時の適用基準

asとasの間には原級を置き、比較級や最上級にはしない。形容詞だけでなくmany booksなどのかたまりも置けるが、`as many as books`のように分断しない。後ろのas以下は比較対象なので、何と同程度なのかを明確に読む。
