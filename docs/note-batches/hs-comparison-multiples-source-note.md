# 高校英語文法「倍数の表し方（twice as … as ～ など）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 基本形 | [Try IT「倍数の表し方」](https://www.try-it.jp/chapters-3897/lessons-3958/) | 倍数を`as … as ～`の前に置く。`twice as … as ～`は2倍、`three times as … as ～`は3倍。 |
| soとの区別 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3897/lessons-3958/) | 倍数表現ではso … asを使わず、必ずas … asを使う。 |
| half | [Try IT同単元の練習](https://www.try-it.jp/chapters-3897/lessons-3958/practice-2/) | `half as … as ～`は「～の半分…だ」。倍数は増加だけでなく0.5倍も表せる。 |

## ノート作成時の適用基準

twice、three times、four times、halfなどの倍数をas … asの直前に置く。asとasの間は形容詞・副詞の原級で、three times as wide as thatのように比較対象を最後に置く。so … asを倍数表現へ混ぜない。
