## ノートに反映する確認済み事項

Try IT公式は、代名詞を前に出た名詞の代わりとして説明し、名詞だけでなく文の一部・全体も表せるとする。人を表す人称代名詞は前に出た人を、`it`は物を表す用法が基本である。文脈上に単独の名詞がなければ、前文全体や文中の名詞句が指示内容になり得るため、代名詞の性質と文の意味を照合する。

ノートでは、先行内容を探す順序、人・物・前文全体の区別、`it`や`this`が指す範囲を復習観点として整理する。個別の設問・解答は転記しない。
