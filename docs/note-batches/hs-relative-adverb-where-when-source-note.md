# 高校英語文法「関係副詞の使い方1（where・when）」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| where | [Try IT「関係副詞の使い方1」](https://www.try-it.jp/chapters-3978/lessons-3999/) | 場所を表す名詞を説明する`in which`は、関係副詞whereに置き換えられる。 |
| when | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-3999/) | 時を表す名詞を説明する`on which`は、関係副詞whenに置き換えられる。 |
| 使用前の確認 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3978/lessons-3999/practice-2/) | whereは`in which`、whenは`on which`と等しい表現である。場所の名詞があるだけでwhereを選ばず、元の前置詞＋関係代名詞の形を確認する。 |

## 対象動画

静的カタログから、正規動画 `zt_Ckx3Kmlc`（関係副詞 where, when①）と `2qPUM6Iv3FI`（関係副詞 where, when②）を確認した。

## ノート作成時の適用基準

場所の先行詞が元の文でin／atなどの前置詞句になるか、時の先行詞がonなどの前置詞句になるかを先に確認する。その上でwhere／whenへ置き換え、関係詞節がどの名詞を説明するかを読み取る。
