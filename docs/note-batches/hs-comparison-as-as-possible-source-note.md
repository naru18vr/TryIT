# 高校英語文法「できるだけ～」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 基本形 | [Try IT「できるだけ～」の表現](https://www.try-it.jp/chapters-3897/lessons-3966/) | `as ～ as possible`、`as ～ as S can`で「できるだけ～」。 |
| 言い換え | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3897/lessons-3966/) | `as soon as possible`と`as soon as you can`は同じく「できるだけ早く」。 |
| 意味のかたまり | [Try IT同単元の練習](https://www.try-it.jp/chapters-3897/lessons-3966/practice-2/) | `as many books as you can`、`as many books as possible`のようにmany booksをまとめてasとasの間に置く。 |

## ノート作成時の適用基準

as … asの間にはsoonやmany booksなど、目標とする程度を表す語句を置く。possibleとS canは言い換え可能だが、主語と時制に応じてcan／couldを判断する。as soon as possibleは定型表現として「できるだけ早く」と訳す。
