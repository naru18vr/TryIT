# 高校英語文法「関係代名詞のthat」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| thatの基本的な位置づけ | [Try IT「関係代名詞のthat」](https://www.try-it.jp/chapters-3978/lessons-3991/) | thatはwhoやwhichの代わりとして使える関係代名詞である。 |
| thatを使う条件 | [Try IT同単元のポイント](https://www.try-it.jp/chapters-3978/lessons-3991/) | 人と物を同時に先行詞とする場合、または先行詞が最上級で修飾される場合にthatを用いる。 |
| 文中での判別 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3978/lessons-3991/practice-2/) | `the most ... that ...`では最上級にかかる関係詞、`人 + 物 + that ...`では人・物をまとめて説明する関係詞として読む。 |

## 対象動画

静的カタログから、正規動画 `VR7esV0WySY`（関係代名詞 that①）と `Vjlwy0ssSqU`（関係代名詞 that②）を確認した。

## ノート作成時の適用基準

先行詞の構成を先に確認する。人と物の組合せならthatを用い、最上級が付いた先行詞を説明する場合にもthatを用いる。thatの後ろを関係詞節として切り出して、先行詞を後ろから説明する構造を読む。
