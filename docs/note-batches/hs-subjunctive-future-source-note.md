# 高校英語文法「未来についての仮定」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| shouldを用いる未来の仮定 | [Try IT「未来についての仮定（should／were to）」](https://www.try-it.jp/chapters-3856/lessons-3877/) | `If＋主語＋should＋動詞の原形` は、起こり得るが可能性の低い未来を表し、「万が一～するならば」と訳す。 |
| were toを用いる未来の仮定 | [Try IT同単元の練習](https://www.try-it.jp/chapters-3856/lessons-3877/practice-2/) | `If＋主語＋were to＋動詞の原形` は、ほとんど起こり得ない未来を表す。 |
| If省略による倒置の関連 | [進研ゼミ高校講座「Had it not been for」](https://benesse.jp/kyouiku/teikitest/kou/english/english/k00121.html) | 仮定法ではifを省略すると倒置が起きるため、文頭の助動詞・be動詞を手がかりに省略されたif節を復元して考える。 |

## ノート作成時の適用基準

未来についての仮定では、通常の未来の条件を表すif節と区別し、話し手が見込む実現可能性の低さを説明する。shouldは「低いが起こり得る」、were toは「ほとんど起こり得ない」と整理する。should節の後ろではwill、would、命令文などが置かれ得る点も、動画の範囲に沿って扱う。
