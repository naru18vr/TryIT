## ノートに反映する確認済み事項

Try IT公式は、`doubt`を「～ではないと思う」という否定的な疑い、`suspect`を「～であると思う」という肯定的な疑いとして区別している。授業で扱う対応関係は、`doubt`がおおむね`don't think`、`suspect`がおおむね`think`である。

練習では、`suspect`を肯定的な推理として、`I do not doubt ...`を強い肯定として読むことを確認する。チャレンジでは、`doubt`が否定の意味を持ち、後続の`any`と結び付いて否定内容を表すことを確認する。ノートでは個別の設問・解答を転記せず、that節の内容を肯定的に見込むのか否定的に見込むのかから動詞を選び、否定形の`do not doubt`を肯定として読み直す復習観点を整理する。
