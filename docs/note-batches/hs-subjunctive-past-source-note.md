# 高校英語文法「仮定法過去」ファクトチェック記録

## 確認した根拠

| 確認項目 | 根拠 | 要点 |
|---|---|---|
| 仮定法過去の対象時制 | [Try IT「Ifを使った仮定法（仮定法過去）」](https://www.try-it.jp/chapters-3856/lessons-3865/) | 仮定法過去は、現在についての現実と異なる内容を過去形で表す。 |
| 基本構文 | [Try IT「Ifを使った仮定法（仮定法過去）」](https://www.try-it.jp/chapters-3856/lessons-3865/) | `If＋主語＋過去形, 主語＋would/could＋動詞の原形`。「もし～ならば、…なのに」を表す。be動詞はwereを使う。 |
| if節・帰結節の役割 | [進研ゼミ高校講座「If onlyのあとに続く仮定法」](https://benesse.jp/kyouiku/teikitest/kou/english/english/k00123.html) | if節は条件を置き、主節はその条件に対する結果を述べる。仮定法過去は現在の事実に反する仮定を表す。 |

## ノート作成時の適用基準

仮定法過去は「過去の出来事」ではなく「現在の事実に反する仮定」であることを明確にする。条件節と結果節を分け、if節は過去形、結果節はwould/could/mightなど＋動詞の原形という対応を説明する。be動詞のwere、hadが過去完了ではなくhaveの過去形として使われる例を混同しないよう扱う。
