## ノート作成に反映する確認済み事項

* 2つだけのうち残りの1つにはthe otherを使う。
* ある1つとは別のもう1つにはanotherを使う。
* 限定された集団の残りすべてにはthe othersを使う。
* `another + 名詞`は「別のもう一つの名詞」を表す。
* `Some people ..., while others ...`は二種類の人を対比して「〜な人もいれば〜な人もいる」を表す。
