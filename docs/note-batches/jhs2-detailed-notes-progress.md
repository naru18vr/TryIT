# 中学2年生・詳しい学習ノート整備の進捗

## 方針

各ノートは、動画内容の確認結果と、必要に応じて公的・教育機関の資料を照合して作成する。要約には学習内容の考え方と手順を含め、覚えるポイントには典型的な間違いと復習時の確認観点を記録する。
