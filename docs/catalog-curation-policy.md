# Try IT学習カタログの精査方針

このアプリでは、映像授業 Try IT の公式チャンネルから取得した公開動画を対象にします。ただし、学習者が教科内容を探す用途に適さない案内・サービス紹介・一般的な勉強法・定期テストの攻略法は、授業カタログから外します。

| 区分 | アプリへの掲載 | 判定例 |
| --- | --- | --- |
| 教科・単元を扱う通常授業 | 掲載 | 学年・教科・単元が題名から分類できる動画 |
| 単元内の確認テスト | 掲載 | 「確認テスト」など、教科内容の復習を目的とする動画 |
| サービス紹介・受講案内 | 除外 | オンライン指導の案内、アプリ・サービスの紹介 |
| 一般的な学習法・テスト攻略 | 除外 | 点数アップ、暗記法、ヤマを張る、初見問題対策 |

除外はタイトルの判定ルールと、確認済みの動画ID一覧で管理します。新しい動画を取り込む場合は、`scripts/build-curated-tryit-catalog.mjs` を実行した後、`pnpm test` のカタログ監査テストを必ず実行します。分類できない動画は自動掲載せず、レビュー対象として `catalog-curation-report.json` の `unmatched` に残します。

> この方針は、Try IT公式チャンネルの動画を「学年→教科→単元」で探しやすくするための運用ルールです。公式チャンネル以外の動画を収録するものではありません。
