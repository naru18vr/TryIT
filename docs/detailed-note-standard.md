# 詳しい学習ノートの記述基準

各動画のノートは、動画の短い説明ではなく、動画を見直す前に学習内容を思い出せる復習用の文章にします。動画・公式説明・公式字幕などで確認できた内容だけを扱い、確認できない発展事項や例外は書きません。

| 項目 | 記述内容 | 目安 |
| --- | --- | --- |
| 要約 | 何を学ぶか、なぜその考え方を使うか、解く流れ | 250〜500字 |
| 考え方 | 定義・見方・使う条件を、初学者にも分かる表現で説明 | 2〜4文 |
| 手順 | 問題を解く順番を、必要な場合に番号付きで整理 | 3〜5段階 |
| よくある間違い | 符号、対応順、数え漏れなど、動画で注意された点 | 2〜4項目 |
| 覚えるポイント | 定義・公式・判断基準・復習時の問いを箇条書きで記載 | 5〜7項目 |

> **事実確認の原則**：用語の定義、公式、数値例、条件は動画内容と教育資料の両方で確認します。動画内の説明が主観的な学習のコツである場合は、「動画では〜と説明している」と限定して記載します。

各ノートは、少なくとも次の問いに答えられる内容にします。

1. この動画で何を理解するのか。
2. どのような順番で考えたり計算したりするのか。
3. どこで間違えやすいのか。
4. 次に動画を見なくても、自分で説明・確認できるか。
