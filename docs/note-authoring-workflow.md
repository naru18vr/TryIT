# 予習復習ノートの整備手順

各動画に表示する「要約」と「覚えるポイント」は、タイトルだけから推測して作成せず、対象動画の内容または公式の字幕・説明欄を確認してから登録します。これにより、学習内容と異なる説明が混ざることを避けます。

| 段階 | 実施内容 | 完了条件 |
| --- | --- | --- |
| 1. 対象選定 | 学年・教科・単元ごとに、利用頻度の高い動画から10本単位で選ぶ | 動画IDと対象単元が確定している |
| 2. 内容確認 | 動画・公式字幕・公式説明欄を確認し、扱う事実と用語を抽出する | 根拠が確認できない表現を含めない |
| 3. ノート作成 | 100〜250字程度の要約と、3〜5個の覚えるポイントを日本語で作成する | 原因・結果、公式、定義などが明確 |
| 4. 登録と確認 | 管理者として動画ページのノート入力欄から保存し、表示を確認する | 要約・覚えるポイントの両方が表示される |

> 初回の確認済みノートとして、「【中学 歴史】昭和時代 動画で学ぶ水俣病」を登録済みです。以後は、中学3年の主要単元と高校基礎科目から順に整備します。

全3,906本を一度に自動生成するのではなく、内容確認済みのノートを単元ごとに追加します。これにより、学習者にとって信頼できる要約・重要ポイントを維持できます。
